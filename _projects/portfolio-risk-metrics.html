What users learn

Volatility describes typical movement; drawdown shows the largest fall from a previous peak; recovery counts how many market sessions it took to regain that peak. Sharpe and Sortino compare return with risk, while VaR, expected shortfall and beta provide additional diagnostic views.

How it works

The package aligns daily, cash-flow-adjusted TWR with an explicit trading calendar and a risk-free series. Every methodology choice—annualisation, downside target, history gate and recovery convention—lives in a versioned machine-readable contract.

Designed to say “unknown”

A missing return is not zero, a not-computed session is not a holiday, and an undefined ratio is not poor performance. Each result carries a status, reasons and observation counts, so the interface can explain why a number is unavailable.

Where it fits

This project consumes TWR from the Portfolio Return Engine. Return Monitoring then checks whether portfolio calculations remain fresh, complete and displayable in daily operation.
