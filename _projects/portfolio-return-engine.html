What it answers

  • TWR: how the investments performed, independent of deposit timing.
  • MWR: the investor's personal outcome, including when money entered and left.
  • Wealth change: the change in account value after separating external cash flows.

How it works

Each transaction type has a written rule. External flows cross the account boundary; trades, fees and corporate actions are internal. The engine builds a daily value series, measures daily performance, links it geometrically and calculates 1M, 3M, 6M, 1Y, YTD and since-entry periods.

Try it

Every output carries a status. Missing data, insufficient history or an unknown transaction type never becomes a misleading 0%.

Hard cases

The tests cover same-day deposits and withdrawals, near-zero starting capital, transferred securities, externally paid dividends, purchase credit, option settlement, multiple valid XIRR roots and missing valuations. These edge cases are where plausible-looking portfolio numbers most often fail.

Where it fits

It consumes validated portfolio inputs and produces the daily TWR used by Portfolio Risk Metrics. Its production outputs are supervised by Return Monitoring.
