Why it matters

A return or risk number can be mathematically correct and still be wrong because a holding, price or corporate action was missing upstream. This project makes those disagreements visible before they reach users.

How it works

Two independent routes describe the same portfolio: a depository feed and a transaction ledger with corporate actions. Each route is checked internally before they are compared. A disagreement becomes an investigation candidate; neither source is silently declared correct.

  • Positive and negative controls show whether a check can detect a known defect without flagging clean data.
  • The replay is report-only: it never repairs or overwrites a source system.

Technical evidence

The repository contains a seeded synthetic dataset, a reproducible defect manifest, Python and SQL checks, range compression, stable fingerprints and Excel exception registers. All 87 tests run without customer or employer data.

Where it fits

This is the first control in the portfolio analytics chain. Trusted inputs feed the Portfolio Return Engine, followed by risk calculation and production monitoring.
